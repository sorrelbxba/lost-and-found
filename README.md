# Lost and Found Website

Lost and Found Website adalah aplikasi web yang bertujuan untuk membantu mahasiswa Fasilkom UI mencari barang yang hilang (Lost) maupun melaporkan barang yang ditemukan (Found).

Melalui website ini, pengguna dapat melihat daftar laporan kehilangan dan penemuan barang, mencari laporan berdasarkan nama barang, melakukan filtering, serta membuat laporan baru.

Website ini dikembangkan menggunakan React.js untuk Frontend, Node.js dan Express.js untuk Backend, serta PostgreSQL sebagai database dengan Prisma ORM.

## Pembagian Tugas

Proyek dikerjakan oleh tiga anggota, yaitu satu Backend Developer dan dua Frontend Developer.

### Backend Developer

*Tugas-tugas wajib buat Checkpoint 1.*

* Setup Backend menggunakan Node.js dan Express.js.
* Mendesain struktur database dan menentukan field laporan beserta tipe datanya.
* Merencanakan Prisma Schema dan relasi database.
* Menyusun REST API Contract (endpoint, HTTP method, request, response, dan status code).
* Menyiapkan mock data yang konsisten dengan API Contract.

### Frontend Developer 1

*Tugas-tugas berikut tidak wajib buat Checkpoint 1, tetapi bisa dicicil.*

* Setup Frontend menggunakan React.js dan Vite.
* Merancang halaman utama dan Report Listing.
* Merencanakan komponen Report Card, Search Bar, Filter, dan Pagination.
* Menentukan struktur routing dan layout responsif.
* Menyesuaikan kebutuhan data Frontend dengan API Contract.

### Frontend Developer 2

*Tugas-tugas berikut tidak wajib buat Checkpoint 1, tetapi bisa dicicil.*

* Merancang halaman Report Detail.
* Merancang halaman dan form Report Submission.
* Menentukan field input dan validasi form.
* Merancang image placeholder dan tampilan informasi kontak.
* Menyusun dokumentasi halaman serta alur penggunaan website.
